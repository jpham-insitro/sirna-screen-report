Strict cascade (each gate must pass to reach the next):
0 · Plate validity (whole-plate, first) — PPIB delivery, FAM13A-pool positive, mock ~100%, Z′ separation, NTC/No-RT clean, GAPDH Cq stable. Any fail → VOID · repeat plate (no siRNA is called).
1 · ΔCt replicate precision — judge %CV on the ΔCt (cycle) scale, not linear % (linear inflates near deep KD). Poor → REPEAT · too noisy.
2 · Monotonic? — %KD rises/flat with dose. Rebound/zig-zag (high-dose tox confound) → FAIL · confound (investigate, don't bin potency).
3 · Efficacy gate (primary flip) — % of pool @top ≥ bar (e.g. ≥80%). Below → FAIL · inactive/weak (a precise KD50 wouldn't matter).
4 · Potency resolution — read potency coarsely from %KD @0.2 nM. Bracketed (transition inside 0.2–20 nM) → HOLD/DROP (coarse KD50 already known). Extrapolated (deep %KD even @0.2 nM → true KD50 below the lowest dose) → ADVANCE to 10-pt.
Advancers: redesign the 10-pt range downward (top ~2 nM into low pM) so the sub-0.2 nM KD50 is interpolated, not extrapolated again. Note: the 3-pt call is deliberately coarser and inverted on potency vs the 10-pt call — you push forward the molecules the screen proved potent but couldn't measure.
